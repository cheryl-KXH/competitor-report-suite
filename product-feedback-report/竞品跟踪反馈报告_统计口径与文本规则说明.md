# 竞品跟踪反馈报告：核心数据口径说明

本文说明报告中的核心数据从哪里来、如何计算以及如何呈现，便于统一理解自动统计结果与人工统计结果之间的差异。

## 一、数据口径

### 1. 外卖数据

- 覆盖美团、饿了么和京东外卖数据。
- 同一平台、门店、商品有多次抓取时，只使用最新一次月销数据，不累加历史抓取结果。
- 月销量为 0 的商品仍视为有售，继续参与统计。
- 商品有上新日期时，按实际在售天数计算；没有上新日期时，按完整 30 天计算。

### 2. 社媒数据

覆盖大众点评、微博、小红书、抖音和 B站五个平台。

- 微博、小红书、抖音、B站按每条数据的情感识别结果统计正向和负向反馈。
- 上述四个平台按数据行数计数，不按用户身份去重。
- 大众点评直接使用人工整理表中的好评用户数、差评用户数和标签评论数。

### 3. 产品信息

新品名称、系列、卖点、价格、原料和产品图片引用周报产品资料中的对应内容，不参与销量或社媒指标计算。

## 二、外卖统计口径

### 1. 在售天数

“上新日期”用于区分新品和常规在售商品：

- **有上新日期**：商品能够在产品资料中匹配到具体上市日期，且该日期处于本次统计关注的近 30 日范围内；人工补充的上新日期也按有上新日期处理。这类商品上市不足 30 天，需要按实际在售天数计算。
- **无上新日期**：商品未匹配到近 30 日内的上市日期，通常代表已上市超过 30 天的常规商品，或资料中没有可用的上市日期。这类商品按完整 30 天计算。

上新日期只用于确定日店均的在售天数分母，不会改变原始月销量。

```text
有上新日期：在售天数 = 抓取日期 - 上新日期 + 1，最多计30天
无上新日期：在售天数 = 30天
```

上新当天计为第 1 天。多门店商品的总在售天数，为各门店在售天数之和。

### 2. 美团、饿了么日店均

两个平台分别计算：

```text
商品总销量 = 各门店最新月销量之和

商品日店均 = 商品总销量 ÷ 各门店在售天数之和
```

日店均反映商品在每个门店、每个实际在售日的平均销量。新品不足 30 天时，按实际在售天数计算，不直接除以 30 天。

### 3. 美团、饿了么线上合计

```text
线上合计日店均 = 美团日店均 + 饿了么日店均

商品线上月销量 = 美团商品总销量 + 饿了么商品总销量

销量占比 = 商品线上月销量 ÷ 全品牌所有商品线上月销量
```

### 4. 销量排名

- 排名按“美团总销量 + 饿了么总销量”从高到低计算。
- 排名不是按日店均计算。
- 销量相同时名次相同，例如 1、1、3。

### 5. 京东外卖

京东源数据代表采集门店看到的“品牌全国销量快照”，因此采用平均口径：

```text
商品京东外卖销量 = 各采集门店最新展示销量之和 ÷ 采集门店数

京东销量占比 = 商品京东外卖销量 ÷ 全部商品京东外卖销量之和
```

京东按上述平均销量排名。由于京东与美团、饿了么的数据含义不同，三者不能直接比较。

## 三、社媒统计口径

### 1. 好评、差评用户数

微博、小红书、抖音和 B站：

```text
好评用户数 = 情感识别为“正向”的数据行数
差评用户数 = 情感识别为“负向”的数据行数
```

大众点评直接取人工整理表中的好评用户数和差评用户数。

### 2. 整体评论量与好评率

```text
好评用户数 = 五个平台好评用户数之和

差评用户数 = 五个平台差评用户数之和

第三方评论总计 = 好评用户数 + 差评用户数

好评率 = 好评用户数 ÷ 第三方评论总计
```

报告中的“评论总计、好评数、差评数”使用的是用户数/数据行数口径，不是标签次数。

### 3. 标签评论数

- 一条反馈可以有多个标签，每个标签分别计数。
- 同一标签在不同评论、不同平台出现时进行累加。
- 因为一条反馈可能对应多个标签，所以标签评论数之和可以大于用户数。

### 4. 主要提及关键词 Top 3

将五个平台的同名标签合并后，分别统计好评和差评高频标签：

- 好评中剔除“好喝，喜欢，推荐”；
- 差评中剔除“难喝，不喜欢，不推荐”；
- 按标签评论数从高到低排序；
- 分别取好评 Top 3 和差评 Top 3。

## 四、报告呈现口径

### 1. 报告开头新品摘要

每款新品展示：

```text
销量排名、线上外卖日店均、销量占比
```

- 销量排名和销量占比按美团、饿了么月销量合计计算。
- 线上外卖日店均为美团日店均与饿了么日店均之和。
- 提前下架、外卖无售或未匹配到销售数据的新品，展示对应状态，不展示正常销量指标。

### 2. 美团&饿了么销量表

展示商品名称、美团日店均、饿了么日店均、线上合计日店均、销量占比和排名。

- 常规展示前 20 名商品。
- 关注新品不在前 20 名时仍保留展示。
- 总计行使用全品牌全部商品计算，不只计算展示商品。

### 3. 京东销量表

展示商品名称、京东外卖销量、销量占比和排名。

- 常规展示前 20 名商品。
- 关注新品不在前 20 名时仍保留展示。
- 京东无数据时显示“京东外卖销售数据暂无法获取”。

### 4. 新品消费者反馈

每款新品分为两部分：

- 反馈汇总：展示评论总计、好评率、好评用户数、差评用户数及好评/差评 Top 3；
- 反馈详情：展示五个平台各自的好评标签、差评标签、标签评论数及好评/差评用户数。

### 5. 数字显示

| 指标 | 报告显示 |
| --- | --- |
| 日店均销量 | 1位小数 |
| 销量占比 | 1位百分比小数 |
| 京东外卖销量 | 整数 |
| 用户数、评论数、标签数 | 整数 |
| 好评率 | 整数百分比 |

系统先使用实际数值完成计算，再按以上位数展示，因此用报告中已经取整的数字反算时，可能存在少量小数尾差。
